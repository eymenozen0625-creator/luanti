GHOST CRAFT, arkadaşlarınla oynamak için yapılmış ücretsiz bir voxel oyunudur. Minecraft benzeri dokular, TV Box desteği ve hayalet temalı macera içerir.

Copyright (C) 2026 Eymen Ozen - GHOST CRAFT Project
Based on Luanti Engine

**Oyun Modları**

1. [OYNA] - Tek oyunculu dünyanı oluştur ve hayatta kal
2. [Ark Ekle] - Arkadaşının IP adresini yaz ve beraber oyna
3. [AYARLAR] - Kontroller, grafik ve ses ayarları
4. [NASIL OYNANIR] - Yeni başlayanlar için rehber

**Kontroller**

| Tuş | İşlem |
|-----|-------|
| W,A,S,D | Yürü |
| Space | Zıpla |
| Fare Sol | Kır / Vur |
| Fare Sağ | Blok Koy / Kullan |
| E / I | Envanter / Karakter |
| Esc | Durdur / Lobi |

**Özellikler**

* TV Kumandası ve Gamepad desteği
* Sadece arklarla oyna - Halka açık sunucu yok
* Bedrock benzeri doku paketi
* Hızlı bağlanma
